# وصّال (Wasal)

وصّال تطبيق أندرويد لمنبّه الوصول إلى **نطاق جغرافي** تختاره. الإصدار المحلي الحالي `1.2.0`؛ الواجهة عربية/إنجليزية، وتظل الوجهات والإعدادات وسجل الرحلات محلية على الجهاز.

> **نتيجة التحقق المحلي:** نجح `testDebugUnitTest` مع **29 اختباراً، بلا فشل أو تخطٍّ**، ونجح `lintDebug` مع **صفر أخطاء وتحذيرين غير مانعين**، ونجح `assembleDebug`. استُخدم JDK 17 وAndroid API 37 وGradle 9.6.0. APK الناتج debug وليس إصدار متجر، ولم يُجرّب على هاتف فعلي. لم يُدفع الفرع ولم يُشغّل GitHub Actions عن بُعد.

## ما يفعله التطبيق

- يتيح اختيار وجهة من بحث صريح يستخدم Android `Geocoder`، أو دبوس الخريطة، أو إحداثيات تدخلها يدوياً. وفي شاشة الأماكن المحفوظة يمكن البحث بكتابة اسم المكان أو عنوانه، ثم اختيار نتيجة لملء الاسم والإحداثيات في نموذج الحفظ. قد يعتمد `Geocoder` على خدمة النظام/اتصال الشبكة؛ لا يوجد autocomplete ولا يطلب التطبيق Nominatim لكل حرف.
- يمكن حفظ حتى **100 مكان** محلياً، مع الاسم والفئة والنطاق. بعد الحفظ يمكن الرجوع إلى الأماكن واستخدامها دون إنترنت.
- يتيح بدء رحلة إلى الوجهة المحددة أو مكان محفوظ. تعرض الواجهة «جارٍ بدء الخدمة» إلى أن تسجل خدمة Android الرحلة فعلياً.
- يتتبع الموقع بواسطة Google Play Services Foreground Location Service بعد بدء واضح من المستخدم، مع إشعار مستمر وأزرار إيقاف/استئناف.
- يستخدم المسافة الجغرافية **بخط مستقيم** لمنطق نطاق التنبيه. ويمكن اختيارياً تفعيل تقدير مسافة طريق للسيارة/التاكسي عبر OSRM الذي تستضيفه FOSSGIS؛ يعرض التقدير منفصلاً ولا يغيّر منطق المنبّه. الميزة متوقفة افتراضياً، وتتطلب موافقة داخل التطبيق.
- يُحسب الطريق من GPS الحالي إلى الوجهة على شبكة الطرق، لا كمسار سيارة أجرة فعلي ولا بيانات مرور. تُرسل الإحداثيات بعد التفعيل فقط، ولا يزيد التحديث على طلب كل 30 ثانية؛ أثناء الثبات يتجدد كل 60 ثانية تقريباً. تتوقف الطلبات عند إيقاف الرحلة مؤقتاً، بعد الوصول، أو عندما لا تكون شاشة الرحلة ظاهرة.
- يتيح إعداد نطاق الوصول من **100 م إلى 50 كم**، وتحذيراً مبكراً اختياريّاً من **100 م إلى 20 كم** خارج النطاق النهائي.
- يستخدم مرحلتين للإنذار: التحذير المبكر لا يصدر إلا بعد قراءتين صالحَتين تُظهران الاقتراب؛ والإنذار النهائي يتطلب قراءتين متتاليتين تقع فيهما دائرة عدم يقين GPS داخل النطاق (`المسافة + دقة القياس ≤ النطاق`). هذه سياسة متحفظة لتقليل الإنذار الكاذب، وقد تؤخره عندما تكون دقة GPS ضعيفة.
- يرفض القياسات غير الصالحة أو الأقدم من دقيقتين، والدقة الأسوأ من نصف النطاق (وبحد أقصى 250 م)، والقياسات خارج الترتيب والقفزات غير المعقولة. هذه المرشحات لا تضمن دقة GPS أو وصول التنبيه في كل جهاز.
- يوفّر إعدادات صوت/اهتزاز، اختباراً محلياً لهما، واختيار صوت من أصوات الجهاز. لا يتجاوز مستوى الصوت أو الصامت أو «عدم الإزعاج» أو سياسة قنوات الإشعارات.
- يوفّر سجل رحلات محلياً حتى **200 رحلة**؛ لا يحفظ مسار GPS مستمراً. يستطيع المستخدم حذف سجل مفرد أو مسح السجل كله. إيقاف حفظ السجل يمنع تسجيل الرحلات الجديدة ولا يمسح السجلات الموجودة.
- يدعم العربية RTL والإنجليزية LTR، ومظهراً فاتحاً/داكناً/حسب النظام، ورسائل لحالات الأذونات والإنترنت والموقع.

## ما لا يدّعيه

- تقدير الطريق اختياري ويحتاج الإنترنت، ولا يتضمن حركة مرور مباشرة أو ETA ولا يضمن أن التاكسي سيسلك المسار نفسه. يعتمد على خادم توجيه عام مجتمعي بلا ضمان SLA؛ قد يتوقف أو يرفض الطلبات. لا يوجد توجيه أو تنبيه وصول للنقل العام.
- بلاطات OSM العامة ليست خرائط offline ولا يجوز تنزيلها جماعياً. قد لا تظهر خريطة جديدة دون إنترنت؛ لكن حساب الرحلة والأماكن المحفوظة يمكن أن يظلا محليين متى توفر GPS.
- استمرار الخدمة وإظهار شاشة القفل best-effort ويتأثر بإصدارات Android والأذونات والبطارية وGoogle Play Services وإعدادات الإشعار والشركة المصنّعة. لا ضمان بعد Force-stop أو إيقاف الجهاز أو قيود OEM.

## التخزين والخصوصية

- الرحلة النشطة محفوظة في سجل `SharedPreferences` محلي بإصدار codec، مع قراءة آمنة للسجل القديم وحدّ حجم، وحفظ متزامن قبل أثر الإنذار. عند سجل تالف تُحفظ نسخة احتياطية محلية محدودة قبل استبداله.
- الأماكن والإعدادات والتاريخ محفوظة في ملف محلي واحد بإصدار schema، وحد أقصى **1,000,000 محرف**، وحدود للأسماء والأعداد، وتحديث read-modify-write ذري على مستوى العملية. لم تُضف Room: النموذج صغير ومحدود ولا يحتاج علاقات/استعلامات معقدة، والإبقاء على التخزين المحلي الحالي يقلل مخاطر ترحيل بيانات الرحلة. إذا توسع الحجم أو احتاج البحث/المزامنة، ينبغي إعادة تقييم Room.
- تُستثنى ملفات التفضيلات الحساسة من Android Auto Backup ونقل الجهاز. لا يطلب التطبيق حساباً ولا يرفع مسار الرحلة المستمر أو الإحداثيات إلى خادم وصّال. مسافة الطريق **متوقفة افتراضياً**؛ وبعد تفعيلها وموافقة المستخدم داخل التطبيق، يرسل Wasal الموقع الحالي والوجهة (بدقة خمس خانات عشرية) إلى خادم FOSSGIS العام، وقد يحتفظ الخادم بسجلات الطلبات. لا تُحفظ طلبات الطريق محلياً.
- تستخدم الخريطة بلاطات `tile.openstreetmap.org` عبر HTTPS مع إسناد ظاهر وسياسة HTTP cache، ما يكشف لمزوّد البلاطات عنوان الاتصال والبلاطات المطلوبة. البحث النصي يمر عبر `Geocoder` الذي يوفره النظام؛ لا ينفذ التطبيق طلبات بحث خلفية متكررة. يعرض مسافة الطريق إسناد OpenStreetMap ورابط الإبلاغ عن أخطاء الخريطة.

## بناء التطبيق محلياً

يتطلب البناء JDK 17 وAndroid SDK API 37. يستخدم Gradle Wrapper الإصدار 9.6.0 مع checksum مثبت، ويستخدم المشروع AGP 9.4.0 وKotlin/Compose 2.4.21.

```bash
./gradlew testDebugUnitTest
./gradlew lintDebug
./gradlew assembleDebug
```

يظهر APK التجريبي في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

تم التحقق من توقيع APK التجريبي محلياً (APK Signature Scheme v2). هذا **ليس توقيع Release** ولا مفتاحاً صالحاً لتحديث تطبيق منشور في متجر. لا يحتوي المستودع على keystore أو أسرار توقيع.

## GitHub Actions

أُحدّث `.github/workflows/android.yml` ليعمل على `push` و`pull_request` و`workflow_dispatch`، ويشغّل اختبارات الوحدة وlint وتجميع APK، ثم يرفع APK وSHA-256 وتقارير JUnit وLint لمدة 30 يوماً. اسم عنصر التنزيل بعد نجاح التشغيل:

```text
wasal-debug-apk-<full-commit-sha>
```

الفرع الحالي `upgrade/wasal-comprehensive-2026-10-13` محلي ولم يُدفع؛ لذلك **لا يوجد تشغيل Actions أو artifact سحابي لهذا التغيير حتى ترفع الفرع**. بعد الرفع: افتح **Actions → Android CI → تشغيل الفرع**، ثم نزّل العنصر من صفحة التشغيل الناجح. لا تخلط بين artifact نجاح البناء ونسخة Release موقّعة.

## الأذونات

- الموقع التقريبي/الدقيق عند بدء الرحلة؛ لا يطلب `ACCESS_BACKGROUND_LOCATION`.
- الإشعارات على Android 13+؛ عند الرفض قد يخفي النظام إشعار الخدمة أو أزراره.
- `FOREGROUND_SERVICE` و`FOREGROUND_SERVICE_LOCATION` لتتبع الرحلة المرئي.
- الإنترنت وحالة الشبكة للبلاطات وبيان الاتصال؛ والاهتزاز والتنبيه حسب تفضيلات المستخدم.
- عند اختيار ميزة مسافة الطريق: الإنترنت لطلب المسار، وإحداثيات GPS الحالية والوجهة إلى خادم FOSSGIS وفق إعداد الميزة وموافقة المستخدم.
- `USE_FULL_SCREEN_INTENT` لعرض شاشة التنبيه حيث يسمح النظام؛ عند المنع يبقى الإشعار fallback.
- لا يطلب جهات اتصال أو كاميرا أو ميكروفون أو أذونات غير لازمة.

## قائمة الاختبار اليدوي المطلوبة

لا يوجد محاكي/جهاز Android موصول هنا، لذلك لم تُنفّذ هذه الحالات يدوياً. اختبر APK على أجهزة وإصدارات مختلفة:

- بدء/إيقاف/استئناف الرحلة، ثم قفل الشاشة وإرسال التطبيق للخلفية.
- سحب إذن الموقع أو تعطيل GPS ثم إعادته؛ GPS ضعيف أو قديم أو قفزة موقع.
- رفض الإشعارات، وتعطيل قناة الإشعار أو full-screen intent ثم تفعيله.
- التحذير المبكر ثم النهائي، اختبار الصوت والاهتزاز، وإيقاف الإنذار من الشاشة ومن الإشعار.
- فقد الإنترنت قبل الرحلة وأثناءها، وإعادة فتح الخريطة، واستخدام مكان محفوظ/إحداثيات دون اتصال.
- تفعيل توجيه السيارة والموافقة على الإفصاح، والتحقق من نسبة OpenStreetMap، تقدير الطريق مقابل الخط المستقيم، throttle الطلبات، عدم الطلب أثناء الإيقاف/بعد الوصول/في الخلفية، وفشل الشبكة أو endpoint.
- إنهاء العملية أو إعادة تشغيل الجهاز، ووضع توفير الطاقة وقيود Xiaomi/MIUI وغيرها.
- حذف سجل منفرد والسجل كله، إيقاف حفظ الرحلات، وترقية التطبيق فوق نسخة سابقة.
